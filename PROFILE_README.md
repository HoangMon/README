### 🚀 Về bản thân (About Me)

- 💻 **Chuyên môn:** Quản trị hệ thống Windows (Windows 10, 11, Windows Server), Xử lý sự cố IT Helpdesk / On-site, và Tối ưu hóa hiệu năng máy tính.
- ⚡ **Lập trình & Tự động hóa:** Phát triển các công cụ tiện ích standalone bằng **C# (.NET 8 WinForms / WPF)**, kịch bản tự động hóa **PowerShell & Batch Script**, tương tác tầng sâu với **Win32 APIs / WMI / Registry**.
- 🛠️ **Dự án tâm huyết:** Tác giả của [Ernastie - IT Tools for Support](https://github.com/HoangMon/it_tools_for_support) — Giải pháp All-In-One hỗ trợ kỹ thuật viên IT, chẩn đoán phần cứng, cấu hình Office/Windows, cứu hộ WinPE và triển khai ảnh hệ thống (Master Image / Sysprep).
- 🎯 **Mục tiêu:** Xây dựng các phần mềm tối ưu cao, portable, tốc độ phản hồi tức thì và không phụ thuộc vào cài đặt môi trường rườm rà.
